# marinozzgroup

Corporate Website for **Marinozz Group** — A modern Food, Restaurant, Confectionery, Retail and Hospitality business ecosystem associated with **Mariners Group**.

## Brands in Ecosystem
- **Marinozz Multicuisine Restaurant** — Flagship Fine Dining, Pan-Asian, Mughlai & Sizzlers
- **Pantoa Sweets & Bakery** — Authentic Bengali Sweets & European Bakery
- **Marinozz Confectionery PLC** — Industrial Commercial Food Processing & FMCG
- **Marinozz PLC** — Supply Chain & Corporate Management Backbone

## Tech Stack
- Next.js (App Router, Turbopack)
- React & TypeScript
- Tailwind CSS
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
